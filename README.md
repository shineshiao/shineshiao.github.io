# shineshiao.github.io

Root of the `shineshiao.github.io` GitHub Pages site. It exists to serve
`app-ads.txt` at https://shineshiao.github.io/app-ads.txt, which AdMob reads
from the developer website set in each free-apps Play listing. The home page
redirects to the privacy policies (`shineshiao/free-apps-privacy`, served at
`/free-apps-privacy/`).

All apps share AdMob publisher `pub-9071509655340557`, so the one line in
`app-ads.txt` covers every app. Keep it in step with the copy at
https://shineshiao.com/app-ads.txt.
